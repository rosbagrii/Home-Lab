### 📂 Home-Lab

Ein zentrales Repository zur Dokumentation meiner IT-Infrastruktur, Systemkonfigurationen und Testumgebungen. 

### 🚀 Projekt-Komponenten

* 💻 Management einer virtuellen Testumgebung mittels **[Hyper-V & Proxmox](./01-virtualization/)**.
* 🌐 **[Netzwerksegmentierung über VLANs](./02-networking/vlan-setup.md)** sowie Konfiguration von **[Linux-Routern und DHCP-Relay](./02-networking/router-config.md)** ([inkl. zentralen Firewall-Regeln](./02-networking/firewall-config.md)).
* 🛡️ Bereitstellung eines Domain Controllers mit den Diensten **[AD, DNS und DHCP](./03-domain_infrastructure)** in einer Domänenstruktur sowie Verwaltung von **[GPOs](./03-domain_infrastructure/gpo.md)**.
* 🐳 Orchestrierung von Web-Projekten mittels **[Docker-Containern](./04-web-apps/docker.md)**.
* ⚙️ Entwicklung von **[Bash-Skripten und Cronjobs](./05-automation/scripts.md)** zur Automatisierung von Systemaufgaben.
* 🗄️ Bereitstellung und Anbindung einer **[MySQL-Datenbank](./04-web-apps/mysql.md)**.
* 💾 Implementierung von Datensicherungen über **[Veeam und Proxmox Backup](./06-monitoring-backup/backups.md)** sowie System-Monitoring via **[Prometheus & Grafana](./06-monitoring-backup/monitoring.md)**.
